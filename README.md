# ❤️ Heart Disease Prediction using Machine Learning

## 🧠 Overview

This project predicts the likelihood of heart disease based on key medical attributes such as age, cholesterol level, blood pressure, chest pain type, and more.

A **Support Vector Machine (SVM)** model is trained on historical patient data to classify whether a person is at risk. The model is deployed using a simple and interactive **Streamlit web application**.

---

## 🚀 Features

* Predicts heart disease risk in real-time
* Clean and interactive web interface
* Pre-trained machine learning model (SVM)
* Scalable and easy to deploy

---

## 🧰 Tech Stack

* **Python**
* **Streamlit**
* **Scikit-learn**
